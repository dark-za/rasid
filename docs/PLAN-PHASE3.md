## البنود المقترحة (تحتاج موافقة المالك قبل التنفيذ)

### 3.1 Alembic لقاعدة `rasid_db` — أولوية عالية
- إضافة alembic إلى `backend/`، ضبط `env.py` على نفس اتصال `database.py` (مستخدم `rasid_app`).
- توليد migration أولي مطابق للمخطط الحالي (`shifts`, `employee_branch_history`) — بدون تغيير بنية.
- استبدال الاعتماد على `Base.metadata.create_all` في `init_db` بـ `alembic upgrade head` (مع fallback واضح عند غياب الأسرار).
- **التحقق**: رفع نظيف على قاعدة فارغة + ترحيل على قاعدة حالية بلا فقدان.

### 3.2 إدارة الورديات CRUD — أولوية عالية
- باكند: `POST /api/shifts` (إضافة)، `PUT /api/shifts/{id}` (تعديل)، `DELETE /api/shifts/{id}` (حذف — يُرفض بـ `409` إن كان هناك اعتماد/سجلات تستخدمه إن أضفنا ربطاً مستقبلاً؛ حالياً حذف بشرط عدم كونها الوحيدة).
- تحقق Pydantic: `start_time`/`end_time` بنص HH:MM، `grace_period_minutes >= 0`.
- واجهة: بطاقات الورديات الحالية تصبح قابلة للتعديل/الحذف + نموذج إضافة.
- **التحقق**: اختبارات pytest للحالات (409، 422، نجاح) + يدوي على الواجهة.

### 3.3 فلاتر تاريخ وموظف في الحضور — متوسطة
- باكند: `GET /api/attendance?date=YYYY-MM-DD&employee_id=16` (افتراضي: اليوم) — يعيد نفس بنية `today`؛ `today` يبقى للتوافق أو يُحوّل الدوال لاستخدام المسار الجديد.
- قيود: `date` ضمن نطاق معقول (مثلاً آخر 90 يوماً) لحماية أداء القراءة.
- واجهة: حقل تاريخ + بحث برقم موظف فوق جدول الحضور.
- **التحقق**: pytest للحدود والحالات + يدوي.

### 3.4 تقارير التأخير — متوسطة
- `GET /api/reports/late?from=...&to=...` : عدد حالات التأخير ودقائقها لكل موظف، مع متوسط.
- الواجهة: بطاقة إحصائية (إجمالي التأخير اليوم/الشهر، أسوأ موظفين).
- ملاحظة أداء: تجميع على الخادم عبر استعلامات نطاقية — لا تحميل كل الأيام في الذاكرة.

### 3.5 CI/CD (اختياري — منخفض المخاطر)
- GitHub Actions: عند push — تثبيت `requirements-dev.txt` + `pytest -q` + بناء الواجهة `npm run build`.
- بلا نشر تلقائي للسيرفر (قرار يدوي للمالك).

### 3.6 اختبارات E2E للواجهة (اختياري)
- Playwright: تحميل الصفحة، إدخال مفتاح، عرض الحضور، إرسال نقل فرع، تفادي 409.
- يُشغَّل محلياً ضد `docker compose up` — ليس شرطاً لبقية البنود.

### 3.7 تحصين الإنتاج (اختياري — يحتاج قرار مالك)
- HTTPS: ضغط على التوصية الحالية (Caddy/Traefik/Cloudflare Tunnel أمام 3005).
- rate limit على `/api/*` (مثلاً slowapi أو nginx `limit_req`).
- بديل مفاتيح: مفتاح لكل مستخدم/جهاز مع إمكانية إبطال، بدل مفتاح عام واحد (يتطلب جدول مستخدمين صغير — يأتي بعد Alembic).
